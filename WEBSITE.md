# Herbion Rose Challenge — размещение на сайте

Готовая веб-версия лежит в папке **`web/`**. Её можно загрузить на любой хостинг и открыть по ссылке с телефона или компьютера.

## Шаг 1. Настройка перед загрузкой

Откройте файл **`js/config.js`** и укажите:

```javascript
window.HERBION_CONFIG = {
  giftEmail: 'ваш@email.ru',   // email для кнопки «Забрать набор Herbion»
  basePath: ''                   // оставьте пустым — путь определится сам
};
```

Если приложение будет в подпапке, например `https://site.ru/rose-challenge/`, укажите:

```javascript
basePath: '/rose-challenge/'
```

## Шаг 2. Загрузка на хостинг

Скопируйте **всю папку `web/`** на сервер через FTP, файловый менеджер хостинга или панель управления.

Пример структуры на сервере:

```
/public_html/rose-challenge/
  index.html
  manifest.webmanifest
  sw.js
  .htaccess
  css/styles.css
  js/config.js, base.js, storage.js, app.js
  icons/...
```

После загрузки приложение откроется по адресу:

```
https://ваш-сайт.ru/rose-challenge/
```

## Шаг 3. Добавить ссылку в меню сайта

### Обычный HTML

```html
<a href="/rose-challenge/">Herbion Rose Challenge</a>
```

### Tilda

1. Добавьте блок **«Кнопка»** или **«Меню»**.
2. В ссылку вставьте: `/rose-challenge/`
3. Текст кнопки: `Rose Challenge` или `Марафон красоты`

### WordPress

1. **Внешний вид → Меню** → добавьте произвольную ссылку.
2. URL: `https://ваш-сайт.ru/rose-challenge/`
3. Сохраните меню.

## Шаг 4. Встроить на страницу (iframe)

Если нужно показать приложение внутри существующей страницы:

```html
<iframe
  src="/rose-challenge/"
  title="Herbion Rose Challenge"
  style="width:100%;max-width:480px;height:780px;border:0;border-radius:24px;margin:0 auto;display:block;"
  allow="clipboard-write">
</iframe>
```

## Шаг 5. Установка на главный экран телефона

После публикации по HTTPS:

| Платформа | Как установить |
|-----------|----------------|
| **Android (Chrome)** | Меню ⋮ → «Установить приложение» / «Добавить на главный экран» |
| **iPhone (Safari)** | Поделиться → «На экран Домой» |

## Проверка после публикации

- [ ] Страница открывается по ссылке с сайта
- [ ] Видны роза, задания и нижнее меню
- [ ] Прогресс сохраняется после перезагрузки
- [ ] Работают светлая и тёмная темы
- [ ] Кнопка «Поделиться» копирует текст
- [ ] «Забрать набор Herbion» открывает почту

## Важно

- Сайт должен работать по **HTTPS** (стандартный SSL на хостинге).
- Не удаляйте папку `icons/` — без неё не будет иконки приложения.
- Файл `.htaccess` нужен для Apache-хостинга (Бегет, Timeweb и др.).

## Содержимое папки web/

| Файл | Назначение |
|------|------------|
| `index.html` | Главная страница приложения |
| `manifest.webmanifest` | Манифест PWA |
| `sw.js` | Service Worker (офлайн-кэш) |
| `js/config.js` | Ваши настройки (email, путь) |
| `css/styles.css` | Стили |
| `icons/` | Иконки для сайта и телефона |
